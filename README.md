# المستشار الزراعي — أداة بحث محلية في قواعد بيانات المبيدات

تطبيق ويب تقدمي (PWA) يعمل **دون إنترنت** بعد أول تحميل، للبحث في قواعد
المبيدات (ليبيا قرار 248 لسنة 2024، ليبيا قرار 500 لسنة 2026، الاتحاد الأوروبي،
USA/EPA — فعالة وملغاة) بالاسم أو رقم CAS، مع مسح بصري محلي (OCR) لملصقات
العبوات، وحزمتين اختياريتين (كندا وأستراليا) تُحمَّلان من لوحة الحزم.

> ⚠️ هذه الأداة مساندة وليست حكمًا قانونيًا. المرجع النهائي هو قرارات وزارة
> الزراعة والجهات الرسمية المختصة. عدم العثور على مادة لا يعني أنها مسموحة.

## البنية

| المسار | الدور |
|---|---|
| `index.html` | الواجهة (شاملة CSS داخلها) |
| `src/app.js` | المنسّق: تحميل القواعد، السجل، ربط المسح البصري |
| `src/search-core.js` | محرك المطابقة (حد العرض 80%) |
| `src/ocr.js` | محرك المسح البصري (tesseract.js 6.0.1 ذاتي الاستضافة؛ eng افتراضيًا وara عند الطلب) |
| `src/ppocr.js` | مانيفست الحزمة الاختيارية PP-OCRv5 (معطّلة افتراضياً؛ لا تُحمَّل بايت واحدة إلا بعلم صريح) |
| `src/i18n.js` | القواميس (ar/en/fr/zh) |
| `sw.js` | عامل الخدمة (كاش `mustashar-v60` + كاش OCR دائم) |
| `data/*.json` | القواعد المرجعية (ليبيا/EU/EPA) لا تُعدَّل يدويًا؛ بيانها في `docs/data-provenance.md` — والحزم الاختيارية في `data-optional/` |
| `scripts/update-intl-dbs.mjs` | وكيل تحديث القواعد الدولية (مصادر EU/EPA الحالية ترجع 404؛ التحديث المعتمد يدوي: EPA ربعيًا عبر `tools/build-epa-master.js`) |
| `src/packs.js` · `src/stats.js` | لوحة الحزم الاختيارية · إحصاءات استخدام محلية (لا تغادر الجهاز) |
| `archive/` | شيفرة قديمة لا تُستخدم (محفوظة للمرجعية فقط) |
| `docs/` | القرارات، سير العمل، بيان المصادر، بروتوكول المراجعة الميدانية |

## التشغيل

أي خادم ملفات ثابت يكفي (لا بناء ولا اعتماديات):

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`. للعمل دون إنترنت: اضغط «⬇️ تجهيز الآن» مرة
واحدة أثناء الاتصال (يخزّن ~15 ميغابايت لملفات محرك المسح البصري).

## الاختبارات

```bash
npm run test:static   # بوابات ثابتة (سلامة القواعد، البنية، OCR، الأسماء)
npm run test:packs    # حزم البيانات الاختيارية
npm run test:browser  # بوابات المتصفح (puppeteer-core + Chrome)
npm run test:a11y     # إتاحة الوصول (axe-core)
node tests/verify.mjs # فحوص بنية/أمان إضافية
```

تُشغَّل البوابة الثابتة تلقائيًا على كل دفع عبر GitHub Actions
(`.github/workflows/gates.yml`)؛ بوابات المتصفح تُشغَّل محليًا لأنها تحتاج
Chrome بنظام.

## الخصوصية

لا تُرفع أي صورة أو بيانات إلى أي خادم. المعالجة كلها على الجهاز، ولا اتصال
إلا لتحميل ملفات التطبيق نفسه عند أول تشغيل أو تحديث.
وإحصاءات الاستخدام (شاشة `#/stats`) محلية أيضاً: عدّادات في متصفحك لا تضمّ
نصوص بحث ولا معرّفاً ولا تغادر الجهاز — التفاصيل في `docs/usage-analytics.md`.
