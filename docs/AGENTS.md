# سياسة وكلاء الذكاء الاصطناعي — المستشار الزراعي

> وثيقة تصريحية فقط: **لا وكلاء عاملين في هذه الجولة**. تُحدَّد هنا مستويات
> الصلاحية قبل أي تفعيل مستقبلي، حتى لا يقوم أي وكيل بعمل خارج الحدود.

## المستويات

| المستوى | الوصف | أمثلة مسموحة | ما يمنع |
|---|---|---|---|
| **0 — قراءة** | يقرأ المستودع ويقترح | مراجعة توثيق، اقتراح صياغات، تلخيص تقارير | أي تعديل، أي شبكة |
| **1 — كتابة محدودة** | يفتح فرعًا + طلب دمج، لا يدفع main | تحديث ترجمات عبر `scripts/agent-translate.md`، سكربتات مساندة | تعديل `src/search-core.js`، `src/ocr.js` المنطق الأساسي، `data/*.json`، عتبات القرار |
| **2 — تشغيل مجدول** | مهمة آلية مجدولة (مثل تحديث القواعد الدولية) | `scripts/update-intl-dbs.mjs` عبر الـworkflow اليدوي/الأسبوعي | الدفع لmain (ينشئ PR فقط)، الكتابة على قواعد ليبيا |

## البوابة الحاكمة لأي وكيل

- **المجموعة المرجعية (golden set)** في `tests/fixtures/labels/` + اختبارات
  `namepairs` و`nearpairs-regression` و`data-health` هي بوابة قبول لأي تغيير
  ينفّذه وكيل: أي فشل فيها يلغي التغيير.
- كل مخرجات وكيل تُراجع بشرًا قبل الدمج — لا دمج ذاتي.

## ممنوعات مطلقة على أي وكيل بأي مستوى

1. لمس `data/libya-248.json` أو `data/libya-500.json` — ليبيا مرجع أول لا يُكتب آليًا.
2. تعديل `src/search-core.js` أو عتبة 80% أو دلالات الحالة القانونية.
3. إرسال أي بيانات مستخدم أو صورة خارج الجهاز، أو توسيع سياسة أمان المحتوى.
4. اختراع مواد فعالة أو أرقام CAS أو حالات قانونية غير موجودة في المصادر.
5. الدفع القسري، إعادة كتابة التاريخ، حذف فروع أو وسوم بعيدة.
