# خطة التنفيذ وتقسيم المسؤوليات — بطاقات التوصيات

**الفرع التجريبي:** `experimental-v2-2026-10-25`  
**المهمة المعتمدة حاليًا:** تحسين التنسيق والألوان والتجاوب لجميع بطاقات التوصيات فقط.  
**قاعدة ثابتة:** لا تعديل على البيانات أو النصوص العلمية أو الصور المصدرية.

## 1. ما ينفذه ChatGPT مباشرة

- مراجعة قرارات المشروع السابقة والقيود الملزمة قبل اقتراح أي تغيير.
- فحص ملفات التصميم والعرض ذات الصلة وتحديد نطاق التعديل، مع التمييز بين بطاقات «التوصيات الزراعية» وبطاقات «الإرشاد».
- إعداد هذا التكليف التفصيلي لوكيل منصة البناء، وإيداعه في المستودع.
- مراجعة تقرير الوكيل والفرق البرمجي ونتائج الاختبارات عند توفرها، ومقارنة التغييرات بالقيود.
- تدقيق أن فروع الإصدار الأول والتجربة منفصلة، وعدم الادعاء بنجاح اختبار أو نشر لم يحدث.
- توثيق المخاطر والعناصر غير المتحقق منها بدل إصلاح البيانات الزراعية ضمن مهمة التصميم.

## 2. ما يجب أن ينفذه وكيل منصة البناء

- فتح المشروع على `experimental-v2-2026-10-25` فقط.
- فحص `index.html` و`src/tawsiyat.js` و`src/tokens.css` قبل أي تعديل.
- تحسين التصميم المرئي لكل بطاقات `#/tws`، بما في ذلك البطاقات الطويلة والجداول وحالات «يحتاج تحققًا»، مع RTL/LTR واستجابة الهاتف وسطح المكتب.
- عدم تعديل `data/**` أو تغيير النصوص أو الأرقام أو الترتيب أو عدد البطاقات أو الصور المصدرية.
- تشغيل اختبارات البيانات/الثبات والإتاحة والمتصفح التي تسمح بها البيئة، وإرفاق النتائج الفعلية ولقطات المعاينة إن أمكن.
- إيداع التغييرات في commit على الفرع التجريبي فقط، دون دمج أو نشر.

## 3. ترتيب التنفيذ

1. **حماية النطاق:** تثبيت فرع العمل ومراجعة commit البداية وعدم لمس نسخة الإصدار الأول.
2. **تحسين العرض:** تغيير CSS/markup الضروري فقط ضمن بطاقات التوصيات.
3. **حارس عدم تغيير البيانات:** فحص diff ومسارات الملفات وبصمات البيانات قبل/بعد.
4. **الاختبار:** static + advice/recommendation + browser + accessibility بحسب ما هو متاح فعليًا.
5. **المراجعة:** يراجع ChatGPT commit والاختبارات والفرق، ويصنف أي قصور.
6. **اعتماد تجريبي داخلي:** لا دمج ولا نشر قبل مراجعة النتائج. أي إطلاق لاحق قرار منفصل.

## 4. معايير إيقاف العمل

أوقف التعديل وأبلغ عن السبب إذا احتاج التحسين إلى تغيير بيانات، أو تغيير منطق التطبيق، أو تنزيل موارد خارجية، أو تعديل فرع محمي، أو تعذر التأكد من أن التعديل محصور في بطاقات التوصيات.
