## توزيع المسؤوليات

### 1. Claude — المحتوى الزراعي
- مواصلة استخراج ومراجعة نصوص كتاب «التوصيات المعتمدة لمكافحة الآفات الزراعية 2025» حسب التعليمات المعتمدة.
- عدم اعتبار أي مخرجات نهائية معتمدة تلقائيًا قبل المقارنة والمراجعة.

### 2. وكيل منصة البناء — واجهة العرض فقط
- تحسين جميع بطاقات `#/tws` على الفرع التجريبي.
- عدم تعديل `data/**` أو النصوص الزراعية أو منطق البحث/المطابقة.
- تشغيل اختبارات العرض والثبات والإتاحة المتاحة، وتوثيق النتائج الفعلية.
- تنفيذ المهمة وفق [البرومبيت المُحدَّث لوكيل منصة البناء](PROMPT-BUILD-AGENT-RECOMMENDATION-CARDS-V2.md).

### 3. ChatGPT — جودة البيانات وتجهيز الاستيراد والمراجعة
- إعداد/مراجعة مواصفة JSON للتحقق من بنية البطاقة، دون إنشاء توصيات أو إعادة صياغة محتوى.
- إعداد أو مراجعة مدقّق يكتشف الحقول الناقصة، والتكرار المحتمل، وCAS غير المؤكد، وترتيب/عدد السجلات، مع تقرير فقط لا تصحيح تلقائي.
- مراجعة تقرير وكيل البناء والـdiff ونتائج الاختبارات عندما تكون متاحة.
- عند تسليم Claude: مقارنة المخرجات بالمصدر وبالبيانات الحالية، وإظهار الفروق للمراجعة البشرية قبل أي استبدال.

## التسلسل العملي

1. يواصل Claude استخراج المحتوى.
2. ينفذ وكيل البناء تحسين الواجهة على بيانات المشروع الحالية فقط.
3. بالتوازي، تُجهز قواعد فحص JSON وثبات البيانات دون توليد محتوى زراعي.
4. نراجع commit الوكيل، والاختبارات، وعدم تغيير `data/**`.
5. عند وصول ملفات Claude، تُفحص أولًا على نسخة منفصلة ويصدر تقرير فروق.
6. لا استبدال لبيانات التوصيات، ولا دمج، ولا نشر، إلا بعد المراجعة والاعتماد الصريح.

- حماية فرع الإصدار الأول وعدم تعديله.
