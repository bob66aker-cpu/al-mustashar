## قواعد لا يجوز تجاوزها
1. لا تعديل على `main` أو فرع الإصدار الأول المحفوظ.
2. لا نشر ولا دمج إلى `work-branch` أو `main` خلال التجارب؛ أي نشر يحتاج قرار إصدار منفصل بعد الاختبارات والمراجعة.
3. لا حذف أو اختصار أو إعادة توليد سجلات قواعد المبيدات أو قرارات ليبيا 248/2024 و500/2026 أو بيانات EU/US. أي تصحيح بيانات مرجعية يجب أن يكون مستندًا إلى المصدر ومراجعًا.

5. لا تغيير أرقام CAS أو الحالة التنظيمية أو الجرعات/فترات الأمان دون مصدر موثوق وتدقيق.
6. لا يُعتبر نجاح الاختبارات الثابتة وحده إثباتًا لصحة الواجهة أو المحتوى أو الصور.
