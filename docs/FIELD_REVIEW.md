# بروتوكول المراجعة الميدانية — المستشار الزراعي v1.2.0

> الغرض: تقييم نسخة «تجريبي للمراجعة الميدانية» على أجهزة وصور حقيقية قبل أي توسع.
> القاعدة الحاكمة: **أي قبول خاطئ (النتيجة تُظهر مادة غير الصحيحة بثقة) عيب حرج يوقف التوسع فورًا** ويُبلَّغ عنه في نفس اليوم.

## 1) الأجهزة المطلوبة

| الجهاز | المتصفح | ما يُقاس عليه |
|---|---|---|
| ويندوز قديم | Chrome (أحدث متاح للجهاز) | زمن البداية الباردة، سلاسة البحث، حجم الذاكرة المستهلك |
| هاتف أندرويد | Chrome | الكاميرا، التثبيت كتطبيق (PWA)، العمل دون إنترنت في الميدان |

## 2) مجموعة الصور المرجعية

- الموقع: `tests/fixtures/labels/` (تُرفع الصور الحقيقية هنا + ورقة الحقيقة المرجعية).
- المجموعة: 14 صورة ميدانية سابقة + 3 مستويات (مثالية / تالفة / ضعيفة الإضاءة) = **17 صورة**، وأي إضافات لاحقة تُرقّم بالاستمرار.
- ورقة الحقيقة المرجعية (يكتبها المستخدم بنفسه من قراءته للملصق، لا من مخرجات القراءة الآلية):

```
image_file, printed_active_ingredient, printed_cas, condition, notes
```

## 3) نموذج تسجيل كل مسح (صف لكل صورة على كل جهاز)

| الحقل | مثال |
|---|---|
| الصورة | `label-07.jpg` |
| الجهاز | هاتف أندرويد |
| ما صُوِّر فعليًا | ملصق كامل / جزء المادة الفعالة |
| ما قُرئ (المادة الفعالة) | Bifenthrin / «لا قراءة» |
| ما ظهر للنتيجة | تام / احتمالي / ملتبس / غير موجود |
| هل هي صحيحة؟ | نعم / لا / غير محسوم |
| الزمن حتى النتيجة | ثانية |
| عدد المحاولات | 1 |
| تصحيح يدوي؟ | نعم/لا + ما عدّله المستخدم |
| **قبول خاطئ؟** | **نعم ← عيب حرج: أوقف التوسع** |

## 4) خطوات تشغيل كل حالة

1. افتح التطبيق من الشاشة الرئيسية (مثبّتًا كتطبيق إن أمكن).
2. فعّل وضع الطيران ثم أعد فتح الصفحة للتأكد من العمل دون إنترنت (أول مرة فقط: اسمح بتنزيل التجهيز الأول ~17 ميغابايت عبر شبكة Wi-Fi).
3. صوّر الصورة المرجعية من الشاشة أو من الطبعة كما هو موضّح في `condition`.
4. اقرأ رسالة فحص جودة الصورة إن ظهرت وأعد التصوير وفقها (بدون تخطيها عن عمد).
5. عند ظهور شاشة تأكيد المادة الفعالة: راجع النص، عدّله إن كان خاطئًا (سجّل ما عدّلته)، ثم ابحث.
6. سجّل النتيجة في نموذج §3 مع تصوير شاشة للنتيجة النهائية.

## 5) تصدير سجل التشخيص ومشاركته

1. بعد كل جلسة: اضغط «⬇️ تصدير سجل التشخيص» في أسفل الصفحة.
2. يُنزَّل ملف JSON يحوي لكل مسح: عدد المحاولات، المتغير الفائز، الزمن، النتيجة — **دون أي صورة**.
3. شارك الملف يدويًا (بريد/واتساب) مع المطوّر — لا يُرسل شيء تلقائيًا من التطبيق.

## 6) معايير النجاح للنسخة التجريبية

| المقياس | الحد |
|---|---|
| قبول خاطئ | **صفر** (أي حالة واحدة توقف التوسع) |
| رفض خاطئ (لا قراءة رغم وضوح الملصق) | يُسجَّل ويُحلَّل — لا يمنع التجربة |
| معدل الوصول للمادة الفعالة | يُقاس ويُسجَّل فقط في هذه المرحلة (لا حده أدنى إلا بعد قياس الخط) |
| زمن المسح الكامل | يُسجَّل؛ تجاوز ~60 ثانية يُلاحظ كعائق قابلية استخدام |
| العمل دون إنترنت | إلزامي 100% بعد أول تجهيز |
