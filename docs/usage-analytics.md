## أ) المنفَّذ الآن — قياس محلي يخرج بصفر بايت

التطبيق يقيس استعماله **على الجهاز وحده**:

| ما يُقاس | العدّاد | أين يُحسب |
|---|---|---|
| فتح التطبيق (جلسة) | `open` + لغة الجلسة | Boot في `src/app.js` |
| كل بحث نصي | `search` ثم `searchHit`/`searchMiss` | `runSearch()` |
| كل قراءة مكتملة للمسح | `scan` ثم `scanHit`/`scanMiss` | `showOcrResults()` |
| تبديل الوضع (محترف/مزارع) | `modePro`/`modeFarmer` | مستمع `#mode` |
| تبديل اللغة | `langSwitch` | مستمع `langchange` |
| التجهيز دون إنترنت | `prep` · `prepOk` · `prepFail` | زر `#prepBtn` |

**التخزين:** `localStorage` بالمفتاح `mustashar-stats` — مخطط محصور
`{ v, since, total, lang, days }` بقائمة عدّادات مُغلقة (`EVENTS`) وحُدَّاد
30 يوماً. **لا نصوص بحث، لا صور، لا معرّف جهاز أو مستخدم، ولا ساعة عشوائية**
— الضوابط تثبت ذلك آلياً في `tests/stats-local.test.mjs`.

**العرض:** شاشة `#/stats` (رابطها في «حول» ← «إحصاءات الاستخدام»): إجماليات،
نسبة البحث المُرجِع، نشاط آخر 14 يوماً، جلسات حسب اللغة، ملاحظة خصوصية، وزر
تصفير. كل الأرقام تُرسم بـ`textContent` و`createElement` فقط (آمن لـ CSP)،
والنصوص مترجمة في القواميس الأربعة.

**ضوابط تبقى خضراء:** الوحدة بلا أي واجهة شبكة (`stats-local`) ·
`network-isolation` 12/12 · ترويسات CSP لم تُمس · وعود README في قسم
«الخصوصية» ما زالت صحيحة حرفياً. الكاش `mustashar-v57→v58` والإصدار
`1.19.21→1.19.22` لأن محتوى القشرة تغيّر (حارس شرائح الإصدار مُحدَّث).

## ب) المسار الخارجي — موثَّق ولم يُفعَّل (يحتاج قرار المالك)

لرؤية استعمال **كل** المزارعين من لوحة واحدة يلزم إرسال أحداث خارج الجهاز،
وهذا يمسّ وعوداً مكتوبة ومُختبَرة:

1. **سياسة الخصوصية في README** («لا تُرفع أي صورة أو بيانات إلى أي خادم»).
2. **CSP** في `index.html` و`_headers`: `connect-src 'self'` يمنع أي
   وبقة خارجية — يجب توسيعه بنطاق الخدمة المختارة.
3. **`tests/network-isolation.test.mjs`** الذي يثبت صفر طلبات خارجية في كل
   جولة — سيعيد كتابة بوابته ليستوعب النطاق المسموح.
4. **`docs/AGENTS.md`**: يمنع الوكلاء توسيع سياسة أمن المحتوى — تنفيذ هذا
   البند يحتاج تفويضاً صريحاً من المالك لا استنتاجاً.

**الخدمات المرشحة** (فهرس التكاملات المتاح، كلها خصوصية-أولى بلا ملفات
تتبّع): `Plausible` · `Fathom` · `Umami Cloud` · `Simple Analytics` ·
`Matomo` (مفتوح المصدر). متطلبات التفعيل عند القرار:

- إنشاء موقع/مفتاح لدى الخدمة ثم ضبط متغيراتها عبر واجهة Freebuff
  (مثلاً `PLAUSIBLE_DOMAIN` و`PLAUSIBLE_API_KEY` لـ Plausible، أو
  `UMAMI_WEBSITE_ID` و`UMAMI_API_KEY` لـ Umami).
- تعديل `connect-src` في meta و`_headers` لاستيعاب نطاق الخدمة فقط.
- تحديث فقرة الخصوصية في README لتصدق بجلسة الإرسال المحدودة.
- تعديل بوابة network-isolation لتعتبر نطاق الخدمة المعتمد استثناءً معلناً.
- تسجيل صفّ قرار جديد في `PROJECT_MEMORY.md` قبل الدفع.

**الوضع:** كل ما سبق غير مفعَّل. الفعالة الوحيدة الحالية هي القياس المحلي
أعلاه، وهي كافية لقياس سلوك الجهاز الذي تفتحه (وتُقاس عليه المعايير)، بينما
يبقى استعمال بقية المزارعين مسجَّلاً كمسار مستقبلي حتى قرار المالك.

## كيف تقرأ الأرقام

افتح «حول» ← «عرض على هذا الجهاز» (أو `#/stats`). «نسبة البحث الذي أرجع
نتائج» = `searchHit ÷ search×100` وهي المؤشر الأصدق على جودة تغطية القواعد؛
و«بحث بلا نتائج» هو مدخل تحسين البيانات. زر التصفير يمحو كل شيء من هذا
المتصفح فوراً.
